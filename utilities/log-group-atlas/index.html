ComponentLog groups
Built from each repo's IaC (CDK / Serverless / Hyperlane hyperlane.json) cross-checked against the live AWS account (4,827 log groups scanned, one region). Re-run when a new service ships or a stack is renamed — CDK-default log group names carry a hash suffix that changes whenever the underlying construct is replaced, so a stack redeploy can silently mint new log groups and orphan the old ones.
